# Prompt 01 — Arranque del proyecto

```
Quiero construir un portal web de empleo para una municipalidad.

El sistema tiene tres tipos de usuario:
- Postulante: se registra, carga su perfil y se aplica a ofertas de trabajo.
- Empresa: se registra y publica ofertas de trabajo para que la municipalidad las apruebe.
- Municipalidad: administra todo — aprueba ofertas, gestiona postulaciones y deriva candidatos a empresas.

Quiero usar Next.js con TypeScript, Supabase para la base de datos y autenticación, y Tailwind CSS para los estilos.

¿Por dónde arrancamos? ¿Qué estructura de proyecto me recomendás y cuáles son las primeras decisiones que tenemos que tomar antes de escribir código?
```
